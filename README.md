# MISI-MENJADI-SIHAT
Misi Sihat: Sehari Jadi Hebat! ialah permainan simulasi interaktif untuk murid Tahun 5 bagi mata pelajaran Pendidikan Kesihatan. Murid akan menjalani rutin harian dari pagi hingga malam sambil mempelajari amalan kebersihan diri, pemakanan seimbang, aktiviti fizikal dan rehat yang mencukupi.
